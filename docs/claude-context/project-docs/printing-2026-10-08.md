## Architecture
- **API — `shared/printing/`** (global PrintingModule): `PrintRegistry` (providers register per document type), `PrintService` (adds company header + the tenant's template), `GET /print/:documentType/:id`, `GET /print/document-types`. Permission per provider (same as opening the document).
- **One shape** for every document: `printDocumentSchema` in `libs/contracts/src/printing/print.contract.ts` (company, party, fields, lines with taxes, totals with tax breakdown + amount in words, notes, supported paper sizes). Template config `printTemplateConfigSchema` (paper size, title, accent colour, show logo/SKU/unit/tax details/amount in words/signatures, header note, terms, footer) stored as JSON in `document_templates.content`.
- **Providers (one small file each)** in `modules/sales/infrastructure/printing/` (sales_invoice A4+80mm, sales_credit_note, payment_received A4+80mm, quotation, sales_order, delivery) and `modules/purchases/infrastructure/printing/` (purchase_order, purchase_invoice, goods_receipt, supplier_payment A4+80mm). Shared helpers in `shared/printing/print-helpers.ts`. A new printable document = one provider + register.
- **Arabic amount in words** (التفقيط) in `libs/shared-kernel/src/text/amount-in-words-ar.ts` (EGP/USD/EUR/SAR/AED/KWD), reusable for cheques.
- **Company profile** (0093): commercial register, phone, email, website, logo (central object storage, `POST/DELETE /settings/logo`, PNG/JPEG/WebP ≤1 MB, resized in the browser). `CompanyProfileService` (settings) gives `logoUrl`.
- **Web**: `/print/:documentType/:id` page outside the app shell (`?paper=thermal80`, `?autoprint=1`), layouts `features/printing/layouts/{a4-layout,thermal-layout}.tsx`, `@page` CSS, "save as PDF" via the print dialog. `<PrintButton documentType id receipt? />` + `openPrint()` in `components/printing/print-button.tsx`, added to all 10 document screens; POS "طباعة الإيصال" after checkout (80 mm, auto-print). Settings › قوالب الطباعة: per-type form with live preview using the real layouts and sample data; Settings › عام: logo + new company fields.
