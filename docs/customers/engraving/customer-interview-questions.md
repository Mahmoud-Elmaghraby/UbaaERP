# أسئلة النقاش مع عميل الحفر على الرخام والبلاط

## الهدف من المقابلة

الهدف إننا نفهم شغل العميل بالتفصيل، عشان نحدد هل محتاج موديول تصنيع كامل ولا أوامر شغل أخف، وإيه الناقص في السيستم.

إزاي تستخدم الورقة:

- اكتب الإجابة في عمود "الإجابة" جنب كل سؤال، حتى لو كانت كلمة واحدة.
- الأسئلة المعلّمة بـ ⭐ هي الأهم. لو الوقت ضيق، ركّز عليها.
- اطلب منه يوريك الشغل على الطبيعة لو ينفع: الورشة والماكينات وورقة الطلب اللي بيكتبها.
- اسأله دايمًا: "إزاي بتعملها النهارده؟" (ورق، إكسل، برنامج تاني)، و"إيه أكتر حاجة بتتعبك فيها؟".

## 1. طبيعة النشاط والمنتجات

القسم ده بيحدد شكل الموديول كله: شغل حسب الطلب، ولا إنتاج للمخزن، ولا خدمة بس.

| # | السؤال | الإجابة |
| --- | --- | --- |
| 1.1 ⭐ | اشرحلي شغلك بكلامك: بتعمل إيه بالظبط؟ (حفر، نقش، كتابة، لوجوهات، لوحات، شواهد، ديكور) | |
| 1.2 ⭐ | بتشتغل على إيه؟ رخام، جرانيت، بلاط، سيراميك، زجاج، خشب، غيره؟ | |
| 1.3 ⭐ | الخامة من عندك ولا العميل بيجيبها؟ ولا الاتنين؟ ونسبة كل واحدة تقريبًا؟ | |
| 1.4 ⭐ | كل شغلك حسب الطلب، ولا فيه منتجات جاهزة بتعملها وتخزنها وتبيعها (زي لوحات آيات شائعة)؟ | |
| 1.5 | بتبيع خامات سادة من غير حفر (بلاط أو رخام بالمتر)؟ | |
| 1.6 | عملاءك مين؟ أفراد، مقاولين، شركات، مساجد، مقابر؟ وهل فيه عملاء ثابتين بالآجل؟ | |
| 1.7 | بتركّب الشغل عند العميل ولا بتسلّمه من الورشة؟ ولو بتركّب، ده بفلوس لوحده؟ | |
| 1.8 | عدد الطلبات تقريبًا في الشهر؟ ومتوسط قيمة الطلب؟ | |

## 2. دورة الشغل من الطلب للتسليم

القسم ده بيحدد مراحل "أمر الشغل" ومين بيتابع كل مرحلة. اخليه يحكيلك آخر طلب اتعمل من أوله لآخره.

| # | السؤال | الإجابة |
| --- | --- | --- |
| 2.1 ⭐ | العميل بيطلب إزاي؟ (زيارة، تليفون، واتساب، صفحة) وبيبعت إيه؟ (صورة، نص، مقاسات) | |
| 2.2 ⭐ | فيه مرحلة تصميم؟ مين بيصمم؟ وهل العميل لازم يوافق على التصميم قبل التنفيذ؟ | |
| 2.3 | التصميم بيتحاسب لوحده؟ ولو العميل طلب تعديلات كتير؟ | |
| 2.4 ⭐ | إيه مراحل التنفيذ بالترتيب؟ (مثال: تصميم ← قص ← حفر ← تلوين/تذهيب ← تلميع ← جاهز ← تسليم) | |
| 2.5 | كل مرحلة بيعملها شخص مختلف؟ وهل محتاج يعرف الطلب واقف في أنهي مرحلة؟ | |
| 2.6 ⭐ | الطلب الواحد ممكن يبقى فيه كذا قطعة مختلفة؟ (مثلًا لوحة + 20 بلاطة) | |
| 2.7 | بتاخد وقت قد إيه من الطلب للتسليم؟ وهل بتلتزم بميعاد تسليم للعميل؟ | |
| 2.8 | لو القطعة اتكسرت أو باظت أثناء الشغل، بيحصل إيه؟ ومين بيتحمل التكلفة؟ | |
| 2.9 | العميل بيتبلغ إن شغله جاهز إزاي؟ (تليفون، واتساب) | |
| 2.10 | فيه مرتجعات أو إعادة شغل بسبب غلطة (اسم غلط، مقاس غلط)؟ | |

## 3. الخامات والمخزون والهالك

القسم ده بيحدد إزاي نسجل الأصناف ووحداتها، وإزاي نحسب الهالك والكسر.

| # | السؤال | الإجابة |

| 3.1 ⭐ | إيه الخامات اللي بتشتريها وتخزنها؟ (ألواح رخام، بلاط، ألوان، ورق دهب، غراء، سنبادات، رؤوس حفر) | |
| 3.2 ⭐ | الخامة الأساسية بتتشترى وتتباع بأنهي وحدة؟ (متر مربع، لوح بمقاس، قطعة، طن) | |
| 3.3 ⭐ | لما تقص قطعة من لوح كبير، الباقي بيحصله إيه؟ بيتستخدم تاني، ولا هالك؟ | |
| 3.4 | نفس النوع بيبقى ليه ألوان أو تخانات أو درجات مختلفة بأسعار مختلفة؟ | |
| 3.5 | نسبة الكسر والهالك تقريبًا؟ وهل مهم تتابعها؟ | |
| 3.6 | عندك مخزن واحد ولا أكتر؟ وهل بتعمل جرد؟ | |
| 3.7 | خامات العميل اللي بيجيبها بتتسجل عندك عشان متتلخبطش مع خاماتك؟ | |
| 3.8 | عدد الأصناف تقريبًا؟ وهل عنده قايمة جاهزة (إكسل)؟ | |

## 4. التسعير وعروض الأسعار

القسم ده بيحدد شكل سطر الفاتورة: بالمتر، ولا بالقطعة، ولا بالحرف.

| # | السؤال | الإجابة |
| --- | --- | --- |
| 4.1 ⭐ | بتسعّر إزاي؟ بالمتر المربع، بالقطعة، بالحرف، بالتصميم، ولا تقديري لكل طلب؟ | |
| 4.2 ⭐ | السعر مكوّن من إيه؟ (سعر الخامة + الحفر + التصميم + التركيب) وهل العميل بيشوف التفاصيل دي في الفاتورة؟ | |
| 4.3 ⭐ | بتكتب المقاسات (طول × عرض) في عرض السعر والفاتورة؟ بالسنتيمتر ولا بالمتر؟ | |
| 4.4 | بتعمل عرض سعر مكتوب قبل الشغل؟ وكام عرض منهم بيتحوّل لشغل فعلًا؟ | |
| 4.5 | فيه أسعار مختلفة لأنواع العملاء (مقاول مقابل فرد)؟ | |
| 4.6 | بتعرف تحسب كان كسبان في كل طلب النهارده؟ وهل عايز تعرف؟ | |

## 5. التكاليف: الماكينات والعمالة والصنايعية

القسم ده بيحدد إزاي نحسب تكلفة كل طلب وربحه الحقيقي.

| # | السؤال | الإجابة |
| --- | --- | --- |
| 5.1 ⭐ | الحفر بماكينة (ليزر، CNC، ساند بلاست) ولا يدوي؟ وكام ماكينة عندك؟ | |
| 5.2 | بتعرف الطلب الواحد بياخد كام ساعة على الماكينة؟ وهل مهم تحسب تكلفة الساعة (كهرباء، استهلاك، صيانة)؟ | |
| 5.3 ⭐ | عندك كام صنايعي وعامل؟ وبياخدوا شهري، ولا يومية، ولا بالقطعة؟ | |
| 5.4 | لو بالقطعة: محتاج السيستم يحسب لكل صنايعي شغله ومستحقاته؟ | |
| 5.5 | فيه شغل بتبعته لورشة تانية (مقاول باطن) زي القص أو التلميع؟ | |
| 5.6 | المصاريف الثابتة الشهرية (إيجار، كهرباء، نقل) بتتسجل فين دلوقتي؟ | |
